# mapa-cassis
Mapa dos produtores de cassis na França (para o sogro). React + Vite + Tailwind + Leaflet, sem backend.
Doc completa: docs/ARQUITETURA.md

- Rodar: `npm run dev` · Checar: `npm test && npm run lint && npm run build`
- Editar a lista: `src/data/producers.js`; cidade nova → `npm run geocode`.
- Publicar: push na `main` (Vercel faz deploy sozinha).
